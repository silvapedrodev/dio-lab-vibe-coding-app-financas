# 💻💸 App de Organização de Finanças Pessoais com Vibe Coding

Este projeto foi desenvolvido como parte de um **Desafio de Projeto da DIO** de **Vibe Coding** utilizando o **Lovable** e o **Copilot Web**.
A proposta é criar um aplicativo de organização financeira pessoal baseado em interações em linguagem natural, permitindo que o usuário converse com um assistente virtual especializado em finanças para gerenciar gastos, metas e relatórios.

## 📝 PRD (Product Requirements Document) Refinado no Copilot Web

```markdown
# PRD – Plataforma de Organização de Finanças Pessoais

## Contexto
Aplicativo de finanças pessoais baseado em conversas.
Objetivo: permitir que o usuário controle seus gastos e metas de forma simples.
Interação principal: chat com assistente virtual especializado em finanças.

## Problema
Apps atuais exigem muita entrada manual.
Pouca personalização e experiência pouco natural.
Usuários desistem do controle financeiro por falta de praticidade.

## Público-Alvo
Pessoas que querem começar a organizar suas finanças sem complicação.
Usuários iniciantes em controle financeiro.
Pessoas que valorizam praticidade e acessibilidade.

## Funcionalidades-Chave
1. Chat Financeiro: registrar gastos e receitas em linguagem natural.
2. Classificação Automática: categorizar transações automaticamente.
3. Metas e Projeções: criar metas financeiras via chat ou manualmente.
4. Operações Financeiras: depósitos, retiradas, transferências e categorização.
5. Relatórios e Dashboards: gráficos e relatórios visuais.
6. Login e Recuperação de Senha: login simples e redefinição direta.
7. Performance e Experiência: skeleton/loading e animações leves.

## Design e UX/UI
Design Universal: responsivo e acessível.
Material Design: seguir padrões de layout e tipografia.
Técnicas de UX/UI: hierarquia visual, feedback imediato, microinterações, consistência.
Paleta de Cores: azul profundo, verdes fechados, destaques em lima neon e tons terrosos.
Dark Mode nativo com transição inteligente para Light Mode.

## Stack Tecnológica
Framework: React + Vite + TypeScript
Estilização: Tailwind CSS
Componentes: Shadcn UI
Ícones: Lucide React
Animações: Magic UI
Validações: Zod (transações, metas, usuário, APIs)

## Entregável da IA
Plano de MVP com telas principais.
Lista de recursos necessários.
Esboço de validação inicial.
Linguagem acessível e educativa em português.
```

## 🛠️ Funcionalidades do App de Organização Financeira

1. **Dashboard Financeiro**  
   - Relatórios visuais com gráficos e dashboards interativos.  
   - Análise detalhada de receitas, gastos e despesas.  
   - Sessão dedicada para acompanhamento financeiro em tempo real.  

2. **Assistente Financeiro**  
   - Registro de gastos e receitas via chat em linguagem natural.  
   - Criação e acompanhamento de metas financeiras.  
   - Execução de operações financeiras: depósitos, retiradas, transferências e categorização.  
   - Responde exclusivamente a temas de finanças e mercado financeiro.  
   - Ignora inputs fora do escopo financeiro.  

3. **Classificação Automática**  
   - Transações são categorizadas automaticamente.  
   - Usuário pode editar categorias existentes ou criar novas manualmente.   

4. **Performance e Experiência**  
   - Skeleton/loading em áreas assíncronas para melhor percepção de carregamento.  
   - Animações leves e performáticas, priorizando a performance do app.  
   - Design responsivo e acessível, baseado em Material Design.  
   - Dark Mode nativo para reduzir fadiga ocular, com transição inteligente para Light Mode.  

6. **Stack Tecnológica**  
   - Framework: React + Vite + TypeScript  
   - Estilização: Tailwind CSS  
   - Componentes: Shadcn UI  
   - Ícones: Lucide React  
   - Animações: Magic UI  
   - Validações: Zod para garantir consistência em transações, metas e dados de usuário

## 🧠 Reflexão

**O que funcionou bem?**  
A integração com o Copilot ajudou bastante na estruturação do PRD, mesmo com poucos créditos disponíveis. O uso do Copilot também foi essencial para definir uma interface moderna e funcional, com foco na experiência do usuário. Isso garantiu que o projeto tivesse uma base sólida antes mesmo da implementação prática.

**O que não funcionou como o esperado?**  
O limite de interações gratuitas no Lovable reduziu a possibilidade de explorar mais cenários e realizar testes adicionais. Apesar de o PRD estar bem estruturado, a aplicação apresentou alguns bugs e erros que não puderam ser corrigidos devido à restrição de créditos. Isso limitou a profundidade da validação prática do projeto.

**O que aprendi sobre conversar com IAs?**  
Aprendi a importância de estruturar prompts de forma clara e detalhada, aplicando técnicas de *Prompt Engineering*. Quanto mais específico e refinado o prompt, melhores são os resultados obtidos. Também percebi que a IA pode atuar como parceira criativa, ajudando a organizar ideias, sugerir melhorias e apontar caminhos que talvez não fossem percebidos em um fluxo tradicional de desenvolvimento. O processo de refinamento contínuo dos prompts mostrou-se essencial para alcançar interações mais produtivas e resultados consistentes.
